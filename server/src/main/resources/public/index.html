ZenTask

A personal, offline-first task manager.

ZenTask is a private task, habit and calendar app built and used by one person. It keeps tasks, lists, tags, habits and countdowns in sync across the owner's own devices through this server, and can show the owner's Google Calendar events next to their tasks (read-only).

ZenTask is not offered to the public and has no sign-up. Source code: github.com/vuhpquang/zentask.
