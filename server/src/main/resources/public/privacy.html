Privacy Policy

ZenTask · Last updated: 8 November 2026

Who we are

ZenTask is a personal app run by its single owner (contact: vuhpq.personal@gmail.com). It has no other users, no advertising and no analytics.

What data ZenTask accesses

When the owner connects a Google account, ZenTask requests one scope: https://www.googleapis.com/auth/calendar.readonly. With it, ZenTask reads the list of calendars and the events in them (title, time, location, description, attendees' status as shown by Google). ZenTask never creates, edits or deletes calendar data.

ZenTask also stores the tasks, lists, tags, habits and countdowns the owner enters in the app.

How the data is used

Calendar events are used only to display them in ZenTask's calendar view next to the owner's tasks, on the owner's own devices.

Where the data is stored

Data is stored on the owner's own server (zentask-api.vuhpquang.com) and on the owner's devices. Google OAuth refresh tokens are encrypted at rest (AES-GCM). Data is transferred only over HTTPS.

Sharing

ZenTask does not sell, share, transfer or disclose Google user data to anyone. It does not use Google user data for advertising, and does not use it to train AI or machine-learning models.

Google API Services User Data Policy

ZenTask's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Calendar events are kept only for the sync window (90 days back, 365 days ahead) and are deleted when the Google account is disconnected in ZenTask's settings. Access can also be revoked at any time at myaccount.google.com/permissions; ZenTask then deletes the stored token and events on its next sync.

Changes

Changes to this policy are published on this page with a new date.
